DavKit demo

Each row is a document in the in-memory H2 database — a Word document, an Excel workbook and a PowerPoint deck, all served by the same provider (the server has no type-specific code; only the link scheme differs). Click Edit in…, enable editing, type, Ctrl+S — then click Refresh. Documents reset when the demo restarts.

No sign-in is needed: Edit in… uses a signed URL (valid PT8H). The optional via OFBA (sign-in) links test Office forms-based login (Windows only), using dave / password.

The demo defaults to local HTTP. If Office refuses to open or save a document, try the optional HTTPS profile described in the README.
