# Reporting a vulnerability

Email [dave@tucanoo.com](mailto:dave@tucanoo.com), the maintainer contact, with `DavKit security`
in the subject. Report suspected vulnerabilities privately rather than in a public issue.
This contact covers the wrapper, demo and its DavKit core dependency.

Include the affected DavKit and framework versions, a description of the impact, and steps
to reproduce with synthetic data. Remove licence keys, signed document URLs, credentials and
customer documents from logs and examples.

This checkout is prerelease software. The demos use permissive access rules and development
credentials; they are not production deployment templates.
